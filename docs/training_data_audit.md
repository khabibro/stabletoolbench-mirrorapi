# MirrorAPI Training Data Audit

joint_sft_cot status: UNVERIFIED

## Official Sources

- MirrorAPI model card, current revision `f181ec673e2346898a0d6453164604bb8372c4fd`, states that MirrorAPI training data consists of `train_sft.json`, `train_cot.json`, and `train_augment.json`.
- MirrorAPI-Training dataset, current revision `94d2a05cbd7f52621c358e0e843bdfa1fd22f945`, provides `train_sft.json`, `train_cot.json`, `train_augment.json`, and `train_cache.json` under MIT license.
- The paper says MirrorAPI uses supervised fine-tuning on real request-response pairs and incorporates CoT rationales generated by OpenAI o1-preview. It also says the model is trained in both SFT and CoT modes using special prompt tokens.
